# Shrine recipes - every item and what the Shrine asks for

These are the owner's final recipes (updated: no ancient debris / netherite anywhere, 64 tuff on every armor piece, heavy core for the Sculk Mace, netherite horse armor + 64 sea lanterns for the Orb (the ONLY netherite in any recipe)); they are also the built-in defaults of the mod. Every recipe needs **1x Magic Essence** (the **Sculk Mace needs 2x**) (`shrinecraft:magic_essence`), which only admins can hand out: `/tuffsmp essence <player> [amount]`.

The four armor pieces are currently called Shrine Helmet / Chestplate / Leggings / Boots (neutral placeholder names; the armor's final identity comes later).

To change a recipe: edit `shrine_recipes.json`, put it in `config/shrinecraft/` on the server or game, then run `/tuffsmp reload`. A potion ingredient is `"item": "minecraft:potion"` plus `"potion": "minecraft:strong_swiftness"`.
